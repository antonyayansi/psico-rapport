# Ejecutable — PsicoRapport

## Archivo incluido

| Archivo | Formato | Descripción |
| --- | --- | --- |
| `PsicoRapport-app-release.aab` | Android App Bundle | Binario de release generado desde el código fuente del programa |

## Nota para el expediente

- Si en el envío anterior ya se presentó un **APK**, indíquelo en la carta de respuesta (“además del APK ya remitido…”).  
- El **AAB** es el formato de distribución de producción en Android; acredita la forma ejecutable del programa.  
- El ejecutable **no sustituye** el código fuente ni la memoria descriptiva; los tres se complementan.
